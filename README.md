# 🚀 SaaS UI Components

> Uma biblioteca open source de componentes modernos, responsivos e reutilizáveis construída com **Next.js**, **Tailwind CSS** e **TypeScript**.

---\n
## ✨ Recursos

- 🎨 **Design Moderno:** Componentes estilizados prontos para produção.
- ⚡ **Super Rápido:** Construído sobre Next.js com Turbopack.
- 📐 **Totalmente Tipado:** Suporte completo a TypeScript.
- 📱 **Responsivo:** Funciona perfeitamente em telas de todos os tamanhos.

---

## 📦 Componentes Disponíveis

### 💳 Pricing Card (Card de Preços)
Card interativo para exibição de planos de assinatura de SaaS, com destaque para planos populares e lista de recursos.

## 🛠️ Como Usar

1. Clone o repositório:
   `ash
   git clone [https://github.com/davicarmomacarau-ux/blibliotecas.git](https://github.com/davicarmomacarau-ux/blibliotecas.git)
   ``n
2. Instale as dependências:
   `ash
   npm install
   ``n
3. Inicie o servidor de desenvolvimento:
   `ash
   npm run dev
   ``n
